# Daily Session + Content Pipeline (DON GIAN - LAP LAI)

## Overview

Implement "Học hôm nay" — a one-button daily learning session centered on dialogue shadowing (read-along per sentence with pinyin + hanzi + Vietnamese + TTS), with vocabulary as support (5-8 keywords per lesson, auto-generated exercises, existing SM-2). Plus content pipeline v2: custom textbook content converted offline (PDF → JSON v2 by AI) and imported through the existing wizard. Philosophy: ĐƠN GIẢN (1 touch to start, 10-15 min session, clear end) — LẶP LẠI (dialogue spaced repetition 1/3/7/14 days, SM-2 for vocabulary).

Design source: `plans/reports/brainstorm-260907-0949-simple-repetitive-daily-session-pipeline-report.md` (approved by user, approach 1).

## Dependencies

- Sequential: Phase 1 → 2 → 3 → 4 → 5 (schema → import → API → UI → test)
- Reuses existing: SM-2 service, TTS hook, import wizard UI, streak logic, `Conversation` model (already in DB, no UI yet)
- Related older plan `260718-mvp-chinese-learning-platform` (status in-progress but effectively delivered) — no hard dependency; this plan supersedes its remaining learning-flow items
- External: user drops textbook PDF into `content-source/pdf/` (workspace root, outside repo) → AI extracts JSON v2 to `content-source/extracted/` → `npm run import:textbook -- <file>` pushes to DB. Wizard upload kept as secondary entry. PDF parsing is NOT an app feature.

## Content Track (parallel with code phases)

Extraction of HSK2 textbook content runs in parallel with phases 1-5. **Handoff doc:** `research/pdf-extraction-workflow.md` (tools, page offsets, verbatim rules, per-lesson schema, merge step). All 15 lessons extracted and imported to DB (171 vocab, 230 conversation lines). HSK1 de-scoped by user decision (solo learner, focusing HSK2). **Work split across sessions:** implementation phases 1-5 owned by session `chinese-learning-f6` (phase 2 import DONE — v2 validated, lesson 1 seeded in DB; now on phase 3); content track + plan owned by this session; session `chinese-learning-01` coordinates docs/vault and runs incremental imports. **Import flow:** `content-source/extracted/import/lesson-NN.import.json` (v2-wrapped, per-lesson, idempotent — course resolves by (type, level)) generated by `merge_lessons_to_v2.py`; this session announces each batch of 3-5 lessons to 01, who imports them.
